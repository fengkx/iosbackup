# 恢复手机数据：先确认手里的备份

[English](restore.md) · [返回操作手册](../OPERATIONS.zh-CN.md)

手机丢失，或数据不小心删掉时，先确认是否有包含所需内容的备份，再选择恢复路线。同一台手机和另一台手机共用这份准备清单；系统版本、容量和新机设置状态可能需要不同处理。

> **验证状态：待真机验证。** 本项目尚未记录将生成的备份交给 Finder / Apple Devices 后完成识别、解密和整机恢复的完整结果。Apple 官方步骤说明这些工具如何恢复电脑备份，不代表已经验证本项目生成的备份兼容。站内整机恢复也仍是默认关闭的实验能力。

## 先保护现有备份

1. 发现误删后，在设备设置中关闭后续自动备份计划，不要立即再运行备份。关闭计划不会取消已经开始的任务；先核对页面状态并等待没有活动写入。
2. 在没有备份或其他写入任务时，按[实例副本指南](instance-recovery.zh-CN.md)保留一致、独立的副本。在副本上检查，不移动或修改唯一原件。
3. 核对备份来源设备、时间和所需数据。项目持续更新同一设备的备份目录，**不会自动保留每次备份的历史版本**。误删后的备份可能已经反映删除状态；寻找误删前另存的副本或 NAS 快照。不能仅凭“最近备份成功”判断其中仍有目标内容。

手机丢失时，来源设备不在身边，并不代表 NAS 上的备份也丢失。先定位已保存的备份和密码；不要把旧设备从管理中删除当作恢复步骤。

## 找到完整的原始备份集

在配置的备份根目录下，来源设备 UDID 对应的目录通常包含 `Info.plist`、`Manifest.plist`、`Status.plist`、`Manifest.db` 及存储数据的散列目录。路径以实际挂载配置为准，见[设备与存储](device-storage.zh-CN.md)。文件存在是初步检查，不是可恢复保证。

- 需要完整、一致的原始备份目录和原加密备份密码。
- CSV 只是文件清单；实验解包的 `_unback_` 输出也不是可替代原始备份的恢复包。
- 管理员密码、应用主密钥、手机锁屏密码都不能代替加密备份密码。[重设备份密码不能解密旧备份](https://support.apple.com/zh-cn/108313)。

## 准备恢复目标设备

| 检查 | 要确认什么 |
| --- | --- |
| 备份内容 | [电脑备份不包含所有数据](https://support.apple.com/zh-cn/108771)，例如部分已同步到 iCloud 的内容；不能承诺所有误删数据都可从本地备份找回。 |
| 系统版本 | 较旧的 iOS 可能无法使用较新系统创建的备份，按 [Apple 的版本说明](https://support.apple.com/en-us/108811)更新后再评估。 |
| 存储容量 | 目标设备应有足够容量容纳恢复内容，不能只按备份目录大小判断。 |
| 当前数据 | 整机恢复会改变目标设备现有状态，不是选几个文件合并。先单独保存当前仍需保留的数据。 |
| 新机状态 | 迁移到另一台已设置的新机时，Apple 的[迁移指南](https://support.apple.com/zh-cn/120001)要求先抹掉并重新设置；不要把此要求套用于所有同机恢复。确认路线和副本后再按官方步骤操作。 |
| 账号与密码 | 准备备份密码以及设置、激活和重新下载内容时需要的 Apple 账号。 |

## 选择恢复路线

| 路线 | 当前说明 |
| --- | --- |
| [Mac：Finder](restore-finder.zh-CN.md) | 优先路线。提供准备和官方恢复入口；本项目备份的识别与实际恢复待验证。 |
| [Windows：Apple Devices](restore-apple-devices.zh-CN.md) | 优先路线。提供准备和官方恢复入口；本项目备份的识别与实际恢复待验证。 |
| [站内实验恢复](experimental.zh-CN.md) | 默认关闭，无完整真机验证。当前按目标设备 UDID 选取备份，不能承诺旧手机备份恢复到不同 UDID 的新手机；不要通过改目录名绕过。 |

若当前唯一可用的备份还未验证，不应把临时实验当作确定可用的恢复方案。先保留原件和一致副本，再评估可用路线。

## 恢复完成后如何核对

完成恢复和后续同步后，解锁设备，抽查所需照片、消息、联系人和关键应用数据；部分内容可能需要登录账号或重新下载。记录来源备份时间、目标机型/iOS、工具版本、加密状态，以及实际检查结果。完成标记和设备重启都不能单独证明所需数据恢复齐全。

这份记录用于补齐验证范围；一种组合的成功不能自动推广到所有设备与系统。失败时保留原件，记录工具错误，分享前删除设备标识、账号和备份内容。

需要恢复的是 NAS 上的服务和配置，而不是手机数据？请看[迁移与恢复部署实例](instance-recovery.zh-CN.md)。只想看清单或区分提取能力，请看[备份查看](inspection.zh-CN.md)。

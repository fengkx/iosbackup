# 在 Mac 上导入 NAS 备份并用 Finder 恢复

[English](restore-finder.md) · [恢复总览与 NAS 导出步骤](restore.zh-CN.md)

适用于 macOS Catalina 10.15 或更新版本。先按[恢复总览的 NAS 导出步骤](restore.zh-CN.md)，从 NAS/Linux 导出完整的来源 UDID 文件夹到 Mac 本地暂存目录，并准备原加密备份密码。Finder 使用这份原始备份，无需导入 iOS Backup 配置或配对记录。

> **待真机验证：** 本文提供项目目录到 Apple 备份目录的具体步骤；本项目尚无 Finder 识别、解密、整机恢复全部完成的验证记录。先完成识别检查，不能识别时不要继续改写手机。

## 1. 放入 Mac 的备份目录

1. 等待电脑的备份/同步任务结束，暂时断开手机并关闭设备管理窗口。保留 NAS 原件和本地导出副本；接下来只复制副本。
2. 在 Finder 按 **Shift–Command–G**，粘贴以下路径。`~` 代表当前登录的 Mac 用户，不是 NAS 用户：

   ```text
   ~/Library/Application Support/MobileSync/Backup/
   ```

   若目录不存在，可在终端运行下列命令创建空目录，再次“前往文件夹”。不要加 `sudo`：

   ```bash
   mkdir -p "$HOME/Library/Application Support/MobileSync/Backup"
   ```

3. 将暂存目录里的**整个来源 UDID 文件夹**复制到 `Backup` 下。保留原目录名，不改成目标手机的 UDID，不把 `data/backups` 或压缩包外层文件夹套进去。
4. 若已存在同名目录，**取消复制，不合并、不替换**。可先在 Finder“管理备份”中对已识别的旧备份使用“归档”（若提供），再核对磁盘目录；也可在无任务且手机断开时，把整个冲突目录移到 `MobileSync/Backup` 之外的受保护位置，保留独立副本后再导入。不要拼接两份备份内部的文件。
5. 确认复制结束、文件可读，最终应在这一层看到清单：

   ```text
   ~/Library/Application Support/MobileSync/Backup/
   └── <来源UDID>/
       ├── Info.plist
       ├── Manifest.plist
       ├── Status.plist
       ├── Manifest.db
       └── 00/ … ff/   （原有数据目录）
   ```

   `Backup/<来源UDID>/<来源UDID>/Info.plist` 是多套一层；`Backup/Info.plist` 则少了设备目录。只修正导入副本的外层位置，保持内部不变。不要用指向 NAS 的符号链接代替本地复制。

## 2. 确认 Finder 能识别这份备份

1. 用 USB 连接**目标手机**，解锁并按提示信任电脑；在 Finder 边栏选择设备，打开“通用”。原机丢失时连接新机，不需要原机在场。
2. 打开“管理备份”，检查来源名称和日期；若提供“在访达中显示”，确认选中的是刚导入的目录。
3. 打开“恢复备份…”的选择窗口，确认能选择所需备份，核对名称、时间和加密提示，先不要确认执行。能显示只证明被识别，不证明密码正确或全部数据可恢复。

使用**“恢复备份…”（Restore Backup）**。“恢复 iPhone…”（Restore iPhone）用于出厂状态/系统恢复，不是选择 NAS 备份的入口。备份选择窗口也不是任意路径选择器，不能直接选择 `.tar.gz` 或 `Manifest.db`。

## 3. 恢复到原机或另一台手机

1. 确认目标设备现有重要数据另有保存、容量足够，已掌握原备份密码和需要的 Apple 账户凭据。NAS 原件保持不动。
2. 已可进入 Finder 的设备从“通用 → 恢复备份…”继续；停在“你好”的新机在设置过程中选“从 Mac 或 PC”再接入电脑。已设置的新机若按迁移流程需要重新进入设置助理，先保存当前数据，再按附录的迁移说明抹掉；不要将“先抹掉”作为所有同机恢复的前置条件。
3. 若提示 iOS 太旧，先升级。尚在设置助理的新机可能需要临时完成设置、不传输数据，升级后再抹掉返回设置助理；只在副本和当前数据已保留后按附录的版本处理流程进行。不要编辑 `Info.plist` 伪造系统版本。
4. 选择核对过的备份，按需输入**原加密备份密码**，再确认“恢复”。若要求关闭“查找”，只对确定要恢复的**目标设备**按提示处理，保留账号凭据；遗失原机的“查找”不属于这一步。
5. Mac 保持供电，保持 USB 连接直到恢复、设备重启和同步完成。按[恢复完成核对清单](restore.zh-CN.md#恢复完成后如何核对)抽查数据，并按需重新启用目标设备的“查找”等保护。

## 无法继续时

| 现象 | 检查与处理 |
| --- | --- |
| 列表没有来源 | 检查 Mac 用户、`Backup/<来源UDID>/Info.plist` 层级、四个文件与数据目录、复制是否结束、当前用户的读取权限。重新连接设备并打开 Finder；仍不识别则保留副本和提示，按未验证兼容性处理。 |
| 只看到今天的电脑备份 | 核对同名目录是否冲突或被新备份更新。不要点击“立即备份”帮助识别，回到独立导出副本核对。 |
| 密码错误 | 使用这份备份的原密码。重置手机备份密码、关闭加密或修改 plist 都不能解密旧备份。 |
| 备份损坏、不兼容或空间不足 | 核对导出校验、复制错误、目标 iOS 和电脑/手机容量。不要从另一份备份补几个文件拼接，也不要反复抹机尝试。 |
| 恢复后缺内容 | 等待后续同步，核对备份日期、iCloud 内容和 App 登录状态；导出成功不代表误删内容曾在备份内。 |
